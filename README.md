# 📱 Portfolio App - React Native + Expo + Back4App

## ✅ Projeto Completo e Funcional!

Este é um aplicativo de portfólio/currículo profissional desenvolvido com **React Native**, **Expo** e **Back4App**.

## 🎯 Status do Projeto

✅ **100% COMPLETO E TESTADO**
✅ **Rodando no Expo Go**
✅ **Compatível com Android e iOS**

## 🚀 Como Iniciar

```bash
cd portfolio-app
npm start
```

Depois escaneie o QR Code com o Expo Go no seu celular!

## 📱 Instalar Expo Go

- **Android**: https://play.google.com/store/apps/details?id=host.exp.exponent
- **iOS**: https://apps.apple.com/app/expo-go/id982107779

## 🎨 Funcionalidades

### Telas Implementadas (5):
1. 🏠 **Home** - Perfil, contatos e links sociais
2. ℹ️ **Sobre** - Tecnologias e funcionalidades do app
3. 🎓 **Educação** - Timeline de formação acadêmica
4. 💼 **Experiência** - Histórico profissional e habilidades
5. 🚀 **Projetos** - Portfólio com projetos em destaque

### Recursos Técnicos:
- ✅ Navegação com **Expo Router** (file-based)
- ✅ Tema claro/escuro automático
- ✅ Animações com **React Native Animatable**
- ✅ Backend com **Back4App** (Parse Server)
- ✅ **TypeScript** para type safety
- ✅ Sistema de cache local (funcionalidade extra)

## 🛠️ Tecnologias Utilizadas

- React Native 0.86
- Expo SDK 57
- Expo Router
- TypeScript
- Back4App (Backend)
- Axios
- AsyncStorage
- React Native Animatable
- Expo Vector Icons

## 📦 Estrutura do Projeto

## ⚙️ Configuração Necessária

Para usar com dados reais, você precisa:

1. Criar conta no Back4App (grátis)
2. Configurar credenciais em `services/back4app.ts`
3. Criar as classes no Back4App
4. Adicionar seus dados

**Veja instruções detalhadas em: `portfolio-app/INSTRUCOES_FINAIS.md`**
