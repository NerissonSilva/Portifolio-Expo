BUILDS:
  npm run build:development    → Build de desenvolvimento
  npm run build:preview        → Build de preview (APK)
  npm run build:production     → Build de produção

UPDATES (OTA):
  npm run update:development   → Update para dev
  npm run update:preview       → Update para preview
  npm run update:production    → Update para produção

🔐 PRÓXIMOS PASSOS (PARA USAR O EAS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. FAZER LOGIN NO EXPO

   eas login

   (Se não tem conta, crie gratuitamente em: https://expo.dev/signup)


2. VINCULAR O PROJETO

   Quando perguntado, escolha "All" para configurar todas as plataformas


3. ATUALIZAR IDENTIFICADORES

   Edite app.json e atualize:
   • ios.bundleIdentifier → "com.seudominio.portfolioapp"
   • android.package → "com.seudominio.portfolioapp"


4. FAZER SEU PRIMEIRO BUILD

   eas build --profile preview --platform android

   O EAS irá:
   • Gerar credenciais automaticamente (se necessário)
   • Fazer o build na nuvem
   • Fornecer um link para download do APK


5. INSTALAR E TESTAR

   • Baixe o APK quando o build terminar
   • Instale no seu dispositivo Android
   • Teste o aplicativo!

⚡ RECURSOS DO EAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔨 EAS BUILD
   • Builds na nuvem (não precisa de Xcode ou Android Studio)
   • Gerenciamento automático de credenciais
   • Builds simultâneos para iOS e Android
   • Histórico completo de builds

🔄 EAS UPDATE
   • Atualizações OTA (Over-The-Air)
   • Publique correções sem rebuild
   • Rollback instantâneo se necessário
   • Compatível com apps nas lojas

🛠️ EXPO DEV CLIENT
   • Ambiente de dev customizado
   • Suporte a bibliotecas nativas
   • Debug avançado
   • Hot reload e fast refresh

💡 EXEMPLO DE USO RÁPIDO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# 1. Login
eas login

# 2. Fazer build de preview
eas build --profile preview --platform android

# 3. Aguardar build terminar (receberá link do APK)

# 4. Fazer uma alteração no código
# (por exemplo, mudar cor, texto, etc.)

# 5. Publicar atualização OTA
eas update --branch preview --message "Atualizei a cor do botão"

# 6. Abrir o app instalado - atualização será baixada automaticamente!

⚠️ NOTAS IMPORTANTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. O EAS BUILD requer uma conta Expo (gratuita)

2. Builds na nuvem são gratuitos com limitações:
   • Plano free: builds ilimitados, mas podem ter fila
   • Plano pago: builds prioritários e mais rápidos

3. OTA Updates são gratuitos para todos

4. Para publicar nas lojas, você precisa:
   • Conta de desenvolvedor Apple ($99/ano) para iOS
   • Conta de desenvolvedor Google ($25 one-time) para Android

5. Atualize os identificadores em app.json antes do build de produção
